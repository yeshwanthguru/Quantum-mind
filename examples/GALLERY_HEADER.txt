Example gallery
===============

Runnable scripts on quantum-like models of people, the COBRA belief filter, robotics, perception and
the Bloch-sphere viewer. Each page shows the code next to its printed output, produced when the documentation was
built. Every script also runs on its own (``python3 examples/<script>.py``), without installing the
package. Only the data in :mod:`quantum_mind.data` are human data; every simulated data set is labelled as
such. The colour of a thumbnail shows the pillar: red quantum-like, blue circuits, green viewer,
orange robotics.

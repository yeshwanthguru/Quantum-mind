# Research claims registry

This file separates what the repository implements from what has been
scientifically demonstrated.

| ID | Claim | Status | Evidence required |
|---|---|---|---|
| CLAIM-001 | Quantum-like models can represent order-sensitive judgement. | Supported as a modelling capability | Mathematical validation and published-data fits. |
| CLAIM-002 | Quantum-like models outperform classical models for HRI prediction. | Unverified | Held-out human/HRI data and paired statistical comparison. |
| CLAIM-003 | Quantum-like uncertainty improves robot ask-vs-act decisions. | Unverified | Same held-out observations, calibrated probabilities, decision-cost analysis and uncertainty intervals. |
| CLAIM-004 | Quantum computing provides an advantage for robot decision-making. | Not established | Matched classical baseline, scaling, resource accounting, noise/hardware evidence and statistical uncertainty. |
| CLAIM-005 | Synthetic HRI experiments demonstrate human behaviour. | False / prohibited claim | Synthetic experiments are debugging and sensitivity evidence only. |

A result should only upgrade a claim's status when its dataset provenance,
comparison protocol, statistical analysis and reproducibility record are
available.
